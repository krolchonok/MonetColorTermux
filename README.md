# MonetColorTermux 🎨

Android-приложение для автоматической синхронизации цветовой схемы **Termux** с системной темой **Android Monet** (Material You).

## ✨ Возможности
- **Синхронизация цветов:** Автоматически извлекает палитру из вашей системы (Android 12+).
- **ANSI Палитра:** Поддержка всех 16 цветов терминала (0-15) для гармоничного отображения интерфейса.
- **Умное переключение:** Утилита `sw` для быстрого переключения между светлой и темной темами внутри Termux.
- **Поддержка оболочек:** Работает в `bash` и `zsh`.

## 🚀 Быстрый старт

### 1. Сборка и установка
Если вы хотите собрать приложение самостоятельно:
```bash
./build_debug.sh
```
*Этот скрипт соберет APK и автоматически установит его на подключенное устройство.*

### 2. Настройка темы
1. Откройте приложение **MonetColorTermux** на смартфоне.
2. Приложение автоматически скопирует установочный скрипт в буфер обмена.
3. Откройте **Termux** и вставьте скопированный текст. Нажмите **Enter**.
4. После установки используйте команду `sw` для смены темы.

## 🛠 Разработка

### Требования
- Android SDK (build-tools 34.0.4+)
- Gradle
- Терминал с установленным `adb`

### Скрипты
- `setup_env.sh` — Настройка окружения (пути к SDK, aapt2).
- `build_debug.sh` — Сборка и установка дебаг-версии.
